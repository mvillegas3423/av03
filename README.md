# AUTO ADVISORS OF AMERICA, LLC — av03

Сайт по продаже и реставрации американской классики: инвентарь, мастерская,
доставка по стране и за рубеж.

**Стек:** Astro 5 (static) · Tailwind CSS v4 (CSS-first `@theme`) · Bebas Neue + Bitter
(локально через `@fontsource`) · зависимостей на рантайме нет.

**Тема:** винтажная Америка. Бумага, бордо, «хром», плакатная типографика, газетные линейки.
Бруксвилл (Флорида), с 1978 года.

## Страницы (22)

| Путь | Что внутри |
|---|---|
| `/` | hero-табличка со стелой «1978», полоса цифр, коллекция (10 машин), прайс-лист работ, архивная галерея, «почему мы», марки, отзывы, CTA |
| `/catalog/` | 10 машин с фильтром по кузову (Coupe, Convertible, Hardtop, Muscle Car, Pickup, SUV…) |
| `/cars/[slug]/` | карточка: фото в рамке-паспарту, «at a glance», «The Story», спецификация со значками, «Equipment» со значками, «More from the floor» |
| `/services/` | 6 работ с ценами: трио плашек сверху, у каждой работы своя иллюстрация |
| `/shipping/` | доставка: закрытый/открытый автовоз, экспресс, экспорт с чеклистом документов, условия |
| `/about/` | «три поколения американского железа»: витрина мастерской, верстак, обещания, отзывы |
| `/contacts/` | телефон, email, адрес, часы, «before you write», 3 вопроса — **без форм** |
| `/privacy/` `/terms/` `/cookies/` `/disclaimer/` `/accessibility/` `/do-not-sell/` | юридический блок (штат Florida, Hernando County) |

## Локально

```bash
pnpm install
pnpm dev        # http://localhost:4321
pnpm build      # сборка в ./dist
pnpm preview

pnpm photos     # img/ -> public/cars/*.webp + *.avif (полный и карточный)
pnpm scenes     # перерисовать 13 иллюстраций в public/scenes
pnpm hero       # фон-заглушка первого экрана
pnpm og         # превью для соцсетей
```

## Данные

- `src/data/site.ts` — бренд, телефон, email, адрес, часы, домен, год основания (1978),
  6 работ с ценами, отзывы, цифры.
- `src/data/cars.ts` — инвентарь: 10 машин, все `featured: true`.
  Поле `hero: true` закрепляет конкретную машину героем главной (сейчас — Chevelle SS 1972);
  без него героем становится самая дорогая из featured.
- Где что менять — пошагово в **`CONFIG.md`**.

## Дизайн

| Токен | Значение | Зачем |
|---|---|---|
| `--color-paper` | `#f3ebdd` | фон страницы (бумага) |
| `--color-cream` | `#faf5ec` | светлые панели |
| `--color-ink` | `#231a14` | основной текст |
| `--color-muted` | `#6b5b4b` | вторичный текст |
| `--color-burgundy` | `#7a2b2b` | акцент: кнопки, ссылки, цены |
| `--color-burgundy-deep` | `#5e1f1f` | hover, рамки CTA |
| `--color-chrome` | `#c8b9a0` | разделители, «хром» |

Шрифты: Bebas Neue (плакатные заголовки капсом) + Bitter (засечный текст).
Классы-примитивы темы: `.display`, `.label`, `.eyebrow`, `.frame`, `.tag`, `.grain`, `.container-x`.

> Контраст — рабочее место этого дизайна: декоративный `--color-chrome` на бумаге даёт всего
> **1.62:1**, поэтому он годится только для рамок и разделителей. Цифры и подписи, которые читает
> человек (номера работ, шаги, марки), сделаны `--color-muted` (5.5:1). Фоновые числа героя — картинка,
> а не текст.

## Иллюстрации и фотографии

- `public/cars/` — фото 10 машин: WebP + AVIF, полный (1000px) и карточный (800px).
- `public/scenes/` — **13 иллюстраций**, нарисованных скриптом `scripts/make-scenes.mjs`
  (SVG → WebP): подъёмник, V8, краскопульт, бампер, салон, бланк оценки, три вида автовоза,
  контейнер с глобусом, витрина гаража, верстак, карта. Используются на Shipping, Restoration,
  About и Contact — пока нет своих фотографий, и как единый визуальный язык.
- `public/hero.jpg` — бумажная плашка-заглушка героя; заменяется на фото машины автоматически,
  когда среди featured появляется машина с фотографией.
- `public/og.jpg` — превью 1200×630, собирается из фото машины (`node scripts/make-og.mjs img/<фото>.jpg`).
